# VIYAAN AI — Beginner Full Stack Student Form

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: SQLite
- Photo upload: Multer

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Open terminal here.
4. Run: `npm install`
5. Run: `npm start`
6. Open: `http://localhost:3000`

## Database
The database is created automatically at `data/students.db`.

## API
- `POST /api/students` → saves form data
- `GET /api/students` → shows all students
- `GET /api/students/:id` → shows one student

## Viva flow
Browser → JavaScript `fetch()` → Express API → SQLite database.

The HTML/CSS design came from the supplied frontend. The form contains the student's name, email, phone, college, department, year, project details and comments.
